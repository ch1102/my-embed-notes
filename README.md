# 学习笔记 · 纯网页版

一个**零依赖、纯前端**的嵌入式学习笔记应用。无需任何构建工具、无需后端、无需安装，
直接用浏览器打开即可使用。数据保存在浏览器 `localStorage` 中，刷新/重开不丢失。

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 首页 | 笔记卡片列表，按**修改时间倒序**；顶部搜索栏按**标题模糊搜索**（实时）；底部悬浮添加按钮（FAB） |
| 新增/编辑 | 标题 + 多行正文；**相机拍照** / **相册选取**插入图片；标签**逗号分隔自动解析**（中/英文逗号，去空白去重） |
| 标签页 | 展示全部标签及数量；点击标签**筛选**该标签下全部笔记 |
| 统计页 | **今日 / 本周**新增数量卡片；**最近 7 天**创建活跃度柱状图（纯 CSS 实现） |
| 交互 | 列表项**左滑删除**手势（触摸与鼠标均支持）；Material Design 3 风格；**跟随系统深色模式自动切换** |
| 数据存储 | `localStorage` 持久化；图片以 base64 内嵌正文，跨刷新/会话可用 |

## 本地运行

### 方式一：直接双击打开（最简单）
直接双击 `index.html` 用浏览器打开即可使用。

> 注意：部分浏览器在 `file://` 协议下会限制 `getUserMedia`（相机）。
> 若要用**拍照**功能，请用方式二通过 `http://` 访问。

### 方式二：本地静态服务器（推荐，相机功能可用）
在本目录下执行任一命令，然后访问 `http://localhost:8091/`：

```bash
# Python（自带）
python -m http.server 8091

# 或 Node
npx serve -l 8091
```

当前环境已为你启动了一个本地服务，访问地址：**http://127.0.0.1:8091/**

## 相机 / 相册权限说明

- **相册**：使用 `<input type="file" accept="image/*">`，无需特殊权限，选图后以 base64 内嵌正文。
- **相机**：使用 `navigator.mediaDevices.getUserMedia`。首次会向用户请求摄像头权限；
  需在 **HTTPS 或 http://localhost** 下才可用（`file://` 直接打开时浏览器会禁用）。
  若拒绝授权，应用会给出友好提示，不影响其它功能。

## 数据存储说明

- 所有笔记以 JSON 数组存入 `localStorage`（键名 `learning_notes_web_v1`）。
- 图片以 `[img:data:image/...;base64,...]` 形式写入正文文本，因此：
  - 不依赖文件系统，浏览器原生即可运行；
  - 刷新、关闭重开均不丢失；
  - 同一个浏览器账号/设备下跨会话可用（但**不会**自动跨设备同步）。
- 数据完全留在本地，不上传任何服务器。如需清空，在浏览器开发者工具中删除对应 `localStorage` 键即可。

## 与 Flutter 版的区别

此前交付过一份 Flutter 版本（含 SQLite）。本纯网页版**不再使用 Flutter / Dart / SQLite**，
改为浏览器原生技术栈，开箱即用、无需安装 SDK 与模拟器。功能集与原需求一一对应。
