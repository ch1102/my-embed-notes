# 学习笔记 

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 首页 | 笔记卡片列表，按**修改时间倒序**；顶部搜索栏按**标题模糊搜索**（实时）；底部悬浮添加按钮（FAB） |
| 新增/编辑 | 标题 + 多行正文；**相机拍照** / **相册选取**插入图片；标签**逗号分隔自动解析**（中/英文逗号，去空白去重） |
| 标签页 | 展示全部标签及数量；点击标签**筛选**该标签下全部笔记 |
| 统计页 | **今日 / 本周**新增数量卡片；**最近 7 天**创建活跃度柱状图（纯 CSS 实现） |
| 交互 | 列表项**左滑删除**手势（触摸与鼠标均支持）；Material Design 3 风格；**跟随系统深色模式自动切换** |
| 数据存储 | `localStorage` 持久化；图片以 base64 内嵌正文，跨刷新/会话可用 |

## 目录结构

```
learning_notes_web/
├── index.html          # 页面结构（底部导航 + 各视图 + 相机弹层）
├── css/
│   └── style.css       # Material Design 3 样式 + 深色模式自适应
├── js/
│   ├── store.js        # 数据层：localStorage CRUD / 搜索 / 标签 / 统计
│   └── app.js          # 交互逻辑：视图切换 / 列表 / 左滑删除 / 编辑 / 相机相册 / 图表
└── README.md
```

## 本地运行

### 方式一：直接双击打开（最简单）
直接双击 `index.html` 用浏览器打开即可使用。

### 方式二：本地静态服务器
在本目录下执行任一命令，然后访问 `http://localhost:8091/`：

```bash
# Python
python -m http.server 8091

# 或 Node
npx serve -l 8091
```
